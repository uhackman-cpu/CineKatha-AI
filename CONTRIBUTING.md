# Contributing

Thanks for your interest in CineKatha-AI. The project is in its architecture/scaffold stage.

## Before contributing
- Open an issue for substantial features or architecture changes.
- Keep integrations behind provider interfaces.
- Never commit API keys, credentials, private source material, or generated user media.
- Include tests and documentation for behavior changes.
- Preserve provenance and license metadata for external assets.

## Development conventions
- Prefer small, focused pull requests.
- Explain trade-offs and operational costs.
- Use mock providers in automated tests.
- Keep paid API usage opt-in.
- Do not mark copyright status as cleared without evidence and human review.

Detailed language, formatting, and test conventions will be added with the first implementation milestone.
