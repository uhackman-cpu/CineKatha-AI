# Local MVP — Story to Cinematic Preview\n\nThis first prototype runs locally. It does not call any hosted AI API and does not need a paid account.\n\n## Requirements\n\n- Python 3.10+\n- FFmpeg (`ffmpeg` command available on PATH)\n- Pillow (`python -m pip install -r requirements.txt`)\n- Optional: `espeak-ng` (or `espeak`) with a Hindi voice for local narration. If unavailable, it still creates a storyboard video and subtitles without speech.\n\n## Run\n\nFrom the repository root:\n\n```bash\ncd backend\npython -m pip install -r requirements.txt\npython cinekatha.py sample_story_hi.txt --title \"आरव और नीला तारा\" --output ../output/arav-preview\n```\n\nThe output directory contains `final.mp4` (if FFmpeg is installed), `project.json`, `subtitles.srt`, `frames/`, and optional `audio/`.\n\n## Current limitations\n\n- This MVP converts story paragraphs/sentences into scenes; it does not yet perform web research or use a language model to write a screenplay.\n- Frames are designed typographic storyboard cards, not generated photorealistic images.\n- Local TTS depends on an installed voice. Hindi voice availability varies by operating system.\n- Long stories can create large output files; start with a short sample.\n- Always use stories and audio/visual assets you own or have permission to use.\n\nNo external network requests, API keys, or paid services are used by the script.\n
